5. 特征构造的数学框架

如果“特征提取”指构造新特征，粗糙集提供了以下数学工具：

5.1 分辨函数与布尔推理

分辨函数 fMf_MfM​ 是一个布尔函数，其素蕴涵项对应约简。通过对 fMf_MfM​ 做布尔化简，可以同时得到所有约简。这属于布尔代数与逻辑化简的范畴。

5.2 属性值约简与规则前件构造

属性值约简是对每个对象，删除其条件属性值中冗余的部分，使得剩余值仍能唯一确定决策。这可以看作从对象层面构造最小特征描述。

5.3 粒计算与特征粒

粗糙集将等价类视为“信息粒”。特征提取可以理解为：

  • 在原始属性空间中构造更粗或更细的粒；

  • 选择一组粒，使得决策类在这些粒上可定义；

  • 粒的合并与分解对应特征的组合与拆分。

5.4 核方法与粗糙集的结合

将粗糙集的依赖度或正域嵌入核函数：

KRS(xi,xj)=∣[xi]B∩[xj]B∣∣[xi]B∪[xj]B∣K_{RS}(x_i,x_j)=\frac{|[x_i]_B\cap[x_j]_B|}{|[x_i]_B\cup[x_j]_B|}KRS​(xi​,xj​)=∣[xi​]B​∪[xj​]B​∣∣[xi​]B​∩[xj​]B​∣​

或用约简后的属性子集构造核。这属于粗糙集与核方法交叉的方向。

Python 生态中粗糙集属性约简的库比较分散，没有类似 scikit-learn 那样的统一标准。以下是几个主要外部库的接口介绍，按经典 Pawlak 约简、约简验证、扩展模型分类。

1. scikit-roughsets（paudan）：最接近 sklearn 风格的约简接口

这是目前接口设计上最“正统”的库，提供 RoughSetsSelector 类，遵循 fit / transform 范式，可直接嵌入 sklearn 的 Pipeline。

安装与核心接口：

python
复制
下载
# pip install scikit-roughsets
from scikit_roughsets.rs_reduction import RoughSetsSelector

selector = RoughSetsSelector()
selector.fit(X, y)          # X 为整数矩阵，y 为整数数组
X_reduced = selector.transform(X)
selected = selector.support_ # 被选中的特征布尔掩码

关键约束：输入 X 必须是整数矩阵（即已离散化），y 必须是整数标签数组。这决定了它只能用于离散决策表，连续特征需先做分箱处理。

该库的文档和社区资料较少，搜索结果中有人反馈“拿不到结果”，说明使用时需要仔细检查输入格式是否符合要求。

2. roughset（Keycatowo）：直接产出约简规则，中文支持友好

这个库的定位不是“返回特征子集”，而是直接生成约简规则，接口围绕 RoughSet 类展开。

安装与核心接口：

# pip install roughset
from roughset import RoughSet

RS = RoughSet(
    df=df,
    name_col="No",                    # 对象标识列
    feature_col=['天气', '事故情形', '事故原因'],  # 条件属性
    decision_col='损坏部位'             # 决策属性
)
rules = RS.create_reduct_rules(include_empty=True)
rules_scored = RS.evaluate_metrics()  # 带支持度/置信度等指标的规则

它的特点是对中文列名支持自然，适合直接处理中文决策表。但不提供独立的属性子集选择接口，约简结果以规则形式返回。该库更新较活跃（2024年仍有提交），但周下载量很低，生产环境需谨慎。-5

3. roughsetkr：面向知识约简的检查式接口

这个库的接口风格与上述两个不同，核心是 RoughSets 类，提供核计算和知识可约简性检查，而不是直接返回一个约简特征子集。

典型用法涉及 RoughSets.cores 查看哪些属性/类别可约简，以及 KnowledgeReduction() 传入候选属性列表来检查约简可行性。它更适合约简的验证性分析，而非自动化特征选择。安装为 pip3 install roughsetkr，依赖较少。

4. scikit-rough（sebow）：偏“检查工具”而非“选择器”

这个库目前提供的主要是约简验证函数，而非直接输出约简的特征选择器。核心接口在 skrough.checks 模块下：-20

from skrough.checks import (
    check_if_reduct,
    check_if_consistent_table,

from skrough.dataprep import prepare_factorized_data

x, x_counts, y, y_count = prepare_factorized_data(df, target_column)
check_if_consistent_table(x, y)          # 决策表是否一致
check_if_reduct(x, x_counts, y, y_count, attrs=[0, 2, 3])  # 给定属性子集是否为约简

它的数据准备函数 prepare_factorized_data 会将 DataFrame 自动因子化，适合需要验证某个候选子集是否满足约简定义的场景。但库本身标注为预发布版本，稳定性有限。

5. frsutils：模糊粗糙集约简的底层工具

如果你的方向涉及模糊粗糙集或邻域粗糙集，frsutils 提供了底层计算接口，包括上下近似、正域和相似度矩阵构造。-26

result = compute_approximations(X, y, model="itfrs", similarity="linear")

它支持 itfrs（Implicator/T-norm）、vqrs（Vaguely Quantified）和 owafrs 等模糊粗糙模型，适合需要计算模糊正域来驱动约简的研究场景。但它不直接提供“返回约简特征列表”的高层接口，约简逻辑需要你在正域分数之上自行构建。-26

选型建议

库接口形态输入要求适用场景
scikit-roughsetsSelector.fit/transform，返回特征子集整数矩阵（已离散化）想要 sklearn 风格、快速嵌入现有流水线
roughsetRoughSet 对象 → 规则DataFrame，指定特征列/决策列想直接得到可解释的 if-then 规则，中文列名友好
roughsetkr检查式接口（核、可约简性）离散决策表约简的验证与分析，而非自动选择
scikit-rough验证函数（check_if_reduct等）因子化后的整数编码需要严格验证某个子集是否满足约简定义
frsutils底层近似计算（正域、相似度）数值矩阵（支持连续）模糊粗糙集/邻域粗糙集研究，需自行构建约简逻辑

最实际的起点：如果你的目标是跑通“输入离散化决策表 → 输出约简特征子集”的完整流程，优先尝试 scikit-roughsets。如果它因为输入格式问题无法顺利运行，roughset 库的规则生成接口可以作为补充——虽然它不直接返回特征子集，但从生成的规则中可以反向确定哪些条件属性被使用，从而得到一个“经验上的约简属性集”。两个库的维护状态和社区规模都有限，遇到问题时直接阅读源码通常是最高效的排查方式。
